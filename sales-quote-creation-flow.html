Sales quote creation in Business Central

The order of API calls the storefront makes to create a quote, send it, and turn it into a sales order. Click any box in the diagram to jump to that call's request and response.

Base URL https://api.businesscentral.dynamics.com/v2.0/{tenantId}/{environment}/api/v2.0

Written as {base} below. Every call after step 1 sends Authorization: Bearer {access_token}; calls with a body also send Content-Type: application/json.

Flow diagram

9 calls, 2 decisions

Main path, every quote Only when needed Outcome: sales order

Step by step

Close the deal

Often days later

  1. 7
    PATCHUpdate quoteoptional {base}/companies({companyId})/salesQuotes({quoteId})

    Headers

    Authorization: Bearer {access_token}
Content-Type: application/json
If-Match: {@odata.etag}

    Body

    { "validUntilDate": "2026-12-31" }

    Response 200 OK

    {
  "@odata.etag": "W/\"JzIwOzE5OTAwMTEyMjMzNDQ1NTY2Nzc7Jw==\"",
  "id": "c3b1d9f4-1a6e-ef11-9f88-6045bdc8c1a7",
  "number": "SQ-1019",

  "totalAmountIncludingTax": 728.85,

}

    Error example 412 Precondition Failed

    {
  "error": {
    "code": "Request_EntityChanged",
    "message": "Could not save the changes because the record was changed by another user."
  }
}

    On 412, read the quote again (step 6) and retry with the new etag.

  2. 8
    POSTSend quote to customer {base}/companies({companyId})/salesQuotes({quoteId})/Microsoft.NAV.send

    Headers

    Authorization: Bearer {access_token}

    Body

    (none)

    Response 204 No Content

    (empty body)

    Business Central emails the quote to the quote's email address and sets status to Sent and sentDate to now.

  3. Customer accepts?
    YesConvert to a sales order (step 9).
    NoLet it expire after validUntilDate, or delete it with the same call as R.
